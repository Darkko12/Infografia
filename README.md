# Infografía interactiva ChatGPT

Proyecto estático en HTML/CSS/JavaScript, pensado para abrirse en Visual Studio Code y publicarse directamente en GitHub Pages.

## Abrir localmente

Podés abrir `index.html` directamente o usar la extensión **Live Server** de VS Code.

## Archivos a reemplazar luego

- `assets/referentes/sam-altman.jpg`
- `assets/referentes/greg-brockman.jpg`
- `assets/referentes/ilya-sutskever.jpg`

Si esos archivos no existen, la web muestra un fallback visual con iniciales.

## Datos pendientes de Figma

En `js/data.js` quedaron marcados como provisionales:

- textos exactos de las tarjetas de GPT-3.5 / GPT-4 / GPT-4o / o1 / GPT-5;
- textos exactos de los tres referentes de OpenAI;
- valores y textos completos del gráfico anual/mensual “Porcentaje del uso”;
- textos del panel descriptivo de cada categoría del donut “Uso de ChatGPT”;
- URLs reales de la bibliografía.

El resto de los valores que fueron confirmados en las exportaciones ya está cargado.
